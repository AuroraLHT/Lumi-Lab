lumi API

This service authenticates users and bridges a browser to the message bus over a single /ws websocket. It serves no application UI — the browser client lives in a separate frontend repository.

  • /docs — interactive API reference (OpenAPI / Swagger UI)
  • /redoc — the same reference, ReDoc rendering
  • /health — liveness plus the list of capabilities currently on the bus

See the project README.md and docs/ for architecture, auth, and the contract-driven bridge.
